# Sprite Souls

A Diablo-like action RPG with class-based progression and a Souls-style
boss rush. Built with Python + [pygame-ce](https://pyga.me); it runs in
the browser as WebAssembly via [pygbag](https://pygame-web.github.io).

### [▶ Play in your browser](https://filipaltdelete.github.io/sprite-souls-release/)

Nothing to install. For Windows, download `SpriteSouls.exe` from the
[latest release](https://github.com/FilipAltDelete/sprite-souls-release/releases/latest).

Web build: **0.0.6** — the two can be released separately, so the
Windows download may be a version ahead or behind.

## Controls

- **Class select** — arrows/AD + Enter, or hover + click
- **WASD / arrow keys** — move
- **Left-click** — attack toward the cursor
- **Space** — attack in the direction you're facing
- **Shift** — dodge: a roll with i-frames for the Knight and the Thief,
  a blink toward the cursor for the Sorcerer
- **E** — guard: the Knight's shield stance (hold; it breaks if held too
  long), the Sorcerer's ward, the Thief's parry
- **Esc** — back to class select

Three classes: the **Knight** sweeps a sword behind a shield, the
**Thief** flurries two knives and parries, the **Sorcerer** casts
fireballs that cost mana. Bosses telegraph every attack with a colored
flash — learn the colors and the fight opens up.
